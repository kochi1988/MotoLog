# MotoLog
Polityka Prywatności – MotoLog

MotoLog przechowuje wszystkie dane wyłącznie lokalnie na urządzeniu użytkownika.
Aplikacja nie przesyła żadnych danych na zewnętrzne serwery.

Dostęp do kamery jest wykorzystywany wyłącznie w celu wykonywania zdjęć motocykli lub dokumentów dodawanych do wpisów w aplikacji. Zdjęcia są zapisywane lokalnie na urządzeniu użytkownika.

Aplikacja nie zbiera danych osobowych, nie udostępnia danych stronom trzecim oraz nie wykorzystuje mechanizmów śledzenia ani analityki.
